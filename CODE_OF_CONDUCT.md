# Code of Conduct

ACLTD is a technical project for reliable agent recovery. We want collaboration to remain focused, respectful, and useful.

## Expected Behavior

- Be precise and evidence-driven.
- Critique code, tests, and design choices rather than people.
- Keep security reports private until maintainers coordinate disclosure.
- Respect review decisions and scope boundaries.
- Assume recovery failures matter and document them carefully.

## Unacceptable Behavior

- Harassment or personal attacks.
- Publishing secrets, credentials, or private operational data.
- Submitting changes intended to bypass branch protection, review, validation, or human authorization.
- Misrepresenting test results or recovery guarantees.

## Enforcement

Maintainers may edit, close, hide, or remove issues, pull requests, comments, or access when behavior threatens the project or its users.
