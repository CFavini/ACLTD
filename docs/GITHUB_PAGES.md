# GitHub Pages Setup

This repository includes a lightweight public page at:

```text

```

## Setup

1. Open repository settings.
2. Go to Pages.
3. Set source to GitHub Actions.
4. Save.

After publication, confirm account-specific links in:

- `README.md`;
- `docs/index.html`;
- `docs/PUBLICATION_GUIDE.md`.
